Como ficou a equação descoberta pela regressão linear simples ?

Uma equação de reta segue o formato \(y = mx + n\).

\[ y = \underbrace{m}*{*\text{coeficiente angular}} x + \underbrace{n}{\text{coeficiente linear}} \]

No exercício: - o valor de m é dado pelo valor do coeficiente angular ; - o valor de n é dado pelo valor do intercepto ;

Então a equação ficou:

\[ y = 0,4750(x) + 3 \]
